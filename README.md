# University student distress and crisis risk — aggregate source data

These four workbooks contain aggregate data for the main figures of “Heterogeneous trajectories of psychological distress and crisis risk in university students.”

| Workbook | Contents |
| --- | --- |
| [Figure 1](Source_Data/Source_Data_Figure_1.xlsx) | Cohort screening, enrolment and confirmed crisis counts |
| [Figure 2](Source_Data/Source_Data_Figure_2.xlsx) | Prediction metrics, model ablations and simulated network recovery |
| [Figure 3](Source_Data/Source_Data_Figure_3.xlsx) | Trajectory summaries, selected coefficients and likelihood-ratio statistics |
| [Figure 4](Source_Data/Source_Data_Figure_4.xlsx) | Warning performance, academic-period comparisons and the summary of paired mood observations |

Blank cells indicate unreported estimates. The repository contains aggregate source data. Requests for participant-level data are handled through the controlled-access process described in the manuscript.
